# Architecture Evaluator — Vite app

This directory is the **React + TypeScript + Vite** application. Repository-level documentation (setup, API, Docker) is in the [root README](../README.md).

```sh
pnpm install
pnpm dev       # http://localhost:5173
pnpm lint
pnpm build
```

The git repository root is one level up (`architecture-evaluator-frontend/`). Do not run pnpm commands from the git root. Use pnpm, not npm or yarn.
