# Architecture Evaluator — Vite app

This directory is the **React + TypeScript + Vite** application. Repository-level documentation (setup, API, Docker) is in the [root README](../README.md).

```sh
npm install
npm run dev    # http://localhost:5173
npm run lint
npm run build
```

The git repository root is one level up (`architecture-evaluator-frontend/`). Do not run npm commands from the git root.
